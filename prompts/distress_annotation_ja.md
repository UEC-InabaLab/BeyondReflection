# タスク説明

カウンセリング対話のクライアント(client)の発話ブロックに対し、苦痛レベル(distress_level)をアノテーションせよ。カウンセラー(counselor)の発話はアノテーションの対象外である。

「発話ブロック」とは、クライアントが連続して投稿した1つ以上の発話のまとまりを指す。クライアントの発話が連続している場合は、それらをまとめて1つのブロックとして解釈し、ブロック全体の内容・文脈に基づいてアノテーションを行うこと。

アノテーションにあたっては発話単体ではなく、それまでの会話の文脈全体を考慮すること。

# 苦痛レベル（distress_level）: 0〜3の整数

- 0（苦痛なし）: 感情的苦痛がほとんど感じられない。中立的・事務的な発話。例：「よろしくお願いします」「最近は仕事が忙しいです」
- 1（軽度）: 軽い不安・悩み・不満が感じられるが、日常的な範囲。例：「少し不安で…」「うまくいかないことが多くて」
- 2（中程度）: 明確な感情的苦痛が表れている。日常生活への影響がある。例：「毎日つらくて眠れません」「会社に行くのが怖いです」
- 3（重度）: 強烈な苦痛、危機的状態、自傷・希死念慮など。例：「もう消えてしまいたい」「限界です」

# 入力形式

入力はJSON形式で与えられる。roleがclientの発話ブロックがアノテーション対象。roleがcounselorの発話はそのまま出力すること。

# 出力形式

出力はJSON形式とすること。入力されたJSONのrole, time, utteranceはそのまま出力すること。

roleがclientのすべての発話に対して、以下の2フィールドをこの順で追加せよ：

- think: 苦痛レベルの判断根拠。そのclient発話が属するブロック全体と文脈を踏まえ、候補レベルを挙げながら最終判断の理由を簡潔に述べよ。
- distress_level: 苦痛レベルの判断値（0〜3の整数）

同一ブロック内（連続するclient発話）はすべて同じ判断値を付与すること。
ブロック内で最初の発話に基づいてブロック全体を評価し、そのブロック内のすべてのclient発話に同一のdistress_levelを付与すること。

出力はマークダウンのコードブロックに囲まれたJSON形式のみとせよ。余計な説明文は不要。
